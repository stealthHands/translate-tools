# OCR language data

The app uses Tesseract's fast English OCR model. It is packaged at `Models/tessdata/eng.traineddata` and copied into the portable publish folder.

## English OCR

The model is from [tesseract-ocr/tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast). Google Translate is used for translation; no translation model is downloaded or run locally.
